# Mario Party 1 Recomp — Android

Android native-recomp port project for Mario Party (USA), following the proven architecture used by the DK64, BM64, Banjo and Golden Balloon Android ports.

## Status

Repository reconstruction in progress after accidental deletion. Target runtime: SDLActivity + N64ModernRuntime + RT64/Vulkan with N64Recomp-generated game code, Android touch/gamepad input, saves and diagnostics.

## ROM

No ROM or Nintendo game data is distributed in this repository. A legally obtained Mario Party (USA) ROM is required locally and verified before use.

## Scope

Single-player/local gameplay. No online or multiplayer server component.
